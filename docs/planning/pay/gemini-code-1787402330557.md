# System Prompt: Metropolis Macroeconomics & Wage Engine

## 1. Core Economic Directives
The economy is closed and tightly controlled. **Do not create random jobs on the fly.** Jobs strictly trace to a predefined occupation matrix triggered by building construction. The player is the only entity that can borrow via the LIBOR bond market; citizens operate on cash-only M1 liquidity.

## 2. Generosity Slider & Base Wages
The global standard of living is controlled by `Generosity` ($G$), where $G \in [-5, 5]$. 

Salary Calculation: $S_{final} = S_{base} \times R_{occ} \times (1 + 0.1G)$
*   $S_{base}$ = Global Baseline Salary (e.g., 50,000)
*   $R_{occ}$ = Occupation Multiplier

## 3. Dynamic Debt & LIBOR Mechanics
Borrowing is dynamically capped by **Net Operating Income (NOI)** ($R_{tax} - E_{civic}$).
*   **Borrowing Capacity:** $C_{debt} = NOI / r_{libor}$
*   **LIBOR Calculation:** $r_{libor} = 0.02 + (0.01 \times G) + \epsilon_{shock}$
*   **Default Trigger:** If required interest payments exceed NOI for 3 consecutive ticks, the city enters Municipal Default (building frozen, output halved).
