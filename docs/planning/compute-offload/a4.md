**Bottom line:**
1. **pix** stays the cheapest for steady play.
2. **Spot VMs on AWS or GCP** are the cheapest paid compute, at roughly the same price:
   - about £3–4 a month for metered 10M play;
   - **£0.68 (GCP) to £1.30 (AWS) per 100M proving run**.

   GCP's 16 GiB c3d Spot machine also covers 30M at about the same price. Both are cheaper than Azure Container Apps as the always-on fallback.
3. The cost of Spot is that **it can be taken away at short notice**. That is acceptable only once:
   - D2 (BUG-1197) snapshots on shutdown;
   - the engine resumes from R2 in seconds;
   - the launcher (§5) can restart it elsewhere.

## 5. The backend-agnostic launcher

Per `a3.md`, Q100159 and Q100160, the engine already runs anywhere a Linux amd64 container runs. Saves live in R2, the single-writer rule is the epoch plus conditional writes, and Cloudflare Tunnel plus Access is the front door. What remains provider-specific is **starting and stopping a city on a host**.

**Proposed: a small `tools/launcher/` with one interface and one adapter per backend.**

```
launcher start  <city> --backend pix|aws-spot|aws-ondemand|azure-aca|gcp-run|hetzner [--size A|B|C]
launcher stop   <city>
launcher status <city>
launcher move   <city> --to <backend>     # stop -> (final snapshot to R2) -> start elsewhere
```

- **Each adapter knows only how to run the same image with the same environment** on its provider: R2 credentials, city key, `GOMEMLIMIT`, the Cloudflare tunnel token, and the active-hours meter budget.
- **Selection rule:**
  1. pix if it is up and the city fits in 8 GB.
  2. Otherwise the cheapest live backend that fits the size: AWS Spot first for metered play and proving runs, Azure Container Apps as the managed fallback.
  3. The cost-gate is consulted before any paid start.
- **Spot reclaim:** the engine already needs a SIGTERM-to-snapshot path (D2). AWS gives a 2-minute warning, so the adapter turns that warning into SIGTERM. The launcher then restarts the city on the next backend. Players see a "Reconnecting…" pause, not a lost city.
- **Effort:**
  - Interface plus the pix and Azure adapters: about 2 days.
  - Each further adapter: about 0.5–1 day.
  - The Spot-reclaim watcher: about 0.5 day.
  - **Prerequisites:** D2 (BUG-1197) and the inc2 R2 store.
