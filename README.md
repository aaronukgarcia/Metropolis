# Metropolis

Private software development project.

## Quick start

Type `metro` in any terminal — it jumps to this folder and launches the Claude Code environment (identity, memory, MCPs, hooks).

## What's here

- `CLAUDE.md` — project brief, Golden Rules, session coordination protocol (read first)
- `docs/golden-rules-detail.md` — full Golden Rules implementation patterns
- `.claude/settings.json` + root `claude-*.js` — Claude Code hooks (version guard, commit policy, identity coordination, memory recall)
- `.claude/commands/` — slash-command skills

Scaffold inherited from the Prix Six project; architecture TBD.
